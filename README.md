# 이약저약 (This Drug That Drug, TDTD)

새 약을 먹기 전에, 현재 복용 중인 약과 확인된 정보를 한 화면에 모아
**확인된 사실과 확인하지 못한 범위**를 보여주고, 약사·의사 상담을 돕는 웹 서비스입니다.

> ⚠️ 이 프로젝트는 학습·포트폴리오용 시연 서비스입니다.
> 실제 복약 판단에 사용하지 마세요. 의사·약사의 상담을 대체하지 않습니다.
